# AI 환경 인식 시나리오

- `static.html`: 바위 정상 인식 / 처음부터 노면 오분류 / 점유 영역 축소
- `dynamic.html`: 걷는 사람 정상 인식 / 부분 분할 오류 / 같은 오류에 추적·이력 방어 적용
- `rough.html`: 거친 노면에서 인식 유지 목표 / 장애물·노면 오분류 / 정지 후 재인식·저속 재출발

`linked-world.js`의 동일 가상 공간과 시간을 상단 카메라·분할·주행 화면, 하단 3인칭 뷰가 공유한다. 재생·일시정지·구간 탐색·조건 변경을 지원한다. 최대 30 FPS, 화면 밖 뷰 생략, 3인칭 렌더 재사용, 합성 단계 블러를 적용한다.

## 표현 기준

페이지의 분할·주행·특징점·관측 큐·비용은 설명용 연출이다. 실제 SegFormer 추론, Lucas–Kanade optical flow, 장애물 추적, 비용 평가 또는 물리 시뮬레이터 실행 결과가 아니다. 동작 예시를 실제 주행 성공·안전성 검증 성과로 인용하지 않는다.

동적 장애물의 이력 방어는 최근 관측을 동일 ID와 이동 위치로 연결해 불안정 비용을 유지하는 설계 예시다. 원시 분할 오류를 그대로 보여주며 마스크를 정답으로 복원했다고 표현하지 않는다. 비용 지수 0~100, 이력 시간, 해제 확인 구간은 설명용 값이다.

`assets/real-motion-blur.jpg`만 사용자가 제공한 2026-10-19 실제 촬영 프레임이다. 촬영 파일명은 `20261019_144253_974600__segment_000007__f000151__t1792388669638439519.jpg`이다. 이 사진은 인식 성능이나 주행 성공 증거가 아니다.

## 실제 시험 자료

페이지 하단에서 조건별 원본·분할·주행 이미지 또는 영상을 브라우저 안에서 열 수 있다. 원본 파일을 서버에 전송하지 않으며 새로고침하면 다시 선택해야 한다. 기록 내려받기는 파일 이름·시험 상태·관측 메모를 JSON으로 저장하며 원본 영상은 포함하지 않는다.

## 수정·배포

정적 HTML이며 빌드나 외부 CDN이 필요 없다. 저장소의 기존 GitHub Pages 배포 방식을 따른다. `scenarios/index.html`에서 세 페이지로 연결한다.
