지면 경사각과 경사 비용 비교

3D 점군 지도저장된 경사 지도
여섯 지도 동시 회전0°

경사 지도 수신 대기

합성 테스트 데이터입니다. 실제 바닥 측정 결과가 아닙니다.

셀 5cm / 평면 계산 반경 7.5cm / 수평면 기준 경사각. 20° 이상은 비용 100입니다. 회색은 미관측, 빗금은 관측했지만 추정 불가입니다.

휠: 여섯 지도 동시 확대 / 왼쪽 드래그: 동시 이동 / 오른쪽 드래그 또는 Shift + 드래그: 동시 회전 / 셀 클릭: 세 방식의 수치 비교. 확대하면 셀마다 숫자가 표시됩니다. 센서 표시 체크박스와 경사 계산은 독립적입니다.

셀을 클릭하면 좌표, 경사각과 비용을 비교할 수 있습니다.

이 지도는 지면 분류와 장애물 검출을 포함하지 않습니다. 5cm 해상도는 측정 정확도를 의미하지 않습니다. 화면의 +X, +Y 화살표는 지도 좌표축입니다. 회전은 화면 방향만 바꾸며 좌표, 경사각과 비용은 바뀌지 않습니다.
