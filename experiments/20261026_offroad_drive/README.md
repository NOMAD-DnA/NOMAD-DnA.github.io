- [장애물 추가 후와 우회 경로](with_obstacles.html)

두 파일은 Three.js와 계산 워커를 포함하는 독립 HTML입니다. 카메라 높이 29cm와 하향 4도, 라이다 높이 30cm와 하향 12도, OAK-D Lite 화각을 기본으로 사용합니다. 울퉁불퉁한 지형에서 점군과 셀별 평면 적합 경사각을 표시합니다.

장애물 버전은 가상 정답 의미분할과 이상적 깊이를 사용합니다. 장애물 우회는 전체 가상 환경을 아는 외부 경로계획기가 성공한다는 가정입니다. 미관측 공간은 주행 가능으로 채우지 않습니다. 실제 학습 모델이나 센서 및 로봇의 성능 검증 결과가 아닙니다.
