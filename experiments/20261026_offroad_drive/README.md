# 주행가능성 시나리오

[통합 HTML 열기](index.html)

하나의 HTML 안에서 위쪽의 시나리오 버튼을 선택합니다. 변경하면 출발점으로 돌아가고 점군, 경사 지도, 의미분할 지도와 경로를 다시 계산합니다. 센서 설치 설정은 유지합니다.

| 번호 | 기본 오르막 | 요철 생성 계수 | 나무와 돌 장애물 |
| --- | --- | --- | --- |
| 1 | 0도 | 0cm | 없음 |
| 2 | 왼쪽 0도, 오른쪽 X 6m부터 10도 | 0cm | 없음 |
| 3 | 0도 | 0cm | 있음 |
| 4 | X 6m부터 25도 | 4cm | 없음 |

1번부터 3번까지는 요철이 없습니다. 3번은 평평한 지면 위에 나무와 큰 돌 장애물을 유지합니다. 4번은 이전 5번의 급경사와 요철을 유지하고 번호만 옮겼습니다. 요철 생성 계수는 실제 최대 고저차를 뜻하지 않습니다. 1번과 3번의 지형 높이는 모든 셀에서 0입니다. 1번과 2번에는 배경 나무도 표시하지 않습니다.

카메라 높이 29cm, 하향 4도와 라이다 높이 30cm, 하향 12도를 기본으로 사용합니다. OAK-D Lite 화각을 가정하며 셀별 경사는 관측한 점군에서 계산합니다. 의미분할은 가상 정답 라벨이며 경로는 전체 가상 환경을 아는 외부 계획기가 성공한다는 가정입니다. 실제 학습 모델이나 센서 및 로봇 성능 검증 결과는 아닙니다.

Three.js와 계산 워커가 내장된 독립 HTML입니다. `?scenario=1`부터 `?scenario=4`까지 링크로 바로 선택할 수 있습니다. 기존 before_obstacles.html과 with_obstacles.html은 이전 링크 호환을 위해 보관합니다.

수정 후 `python3 source/build.py`로 통합 HTML을 생성합니다.
빌드하면 시나리오 자료함의 링크에 HTML 내용 해시를 버전값으로 붙여 이전 HTML 캐시가 재사용되지 않도록 합니다.

주행 가능한 경사 한계는 사용자 조건인 20도입니다. 별도의 전방 경사 판정기가 현재까지의 LiDAR와 카메라 지면 관측을 합치고 전방 0.6~1.2m의 국소 평면을 추정합니다. 경사 추정치가 20도를 초과하면 정지하며, 4번에서는 장애물 없이 급경사 앞에서 정지하는 것을 확인합니다. 시작 높이 절단과 지도 표시 옵션은 정지 판정용 입력과 별개입니다. 위치 슬라이더와 도착 지도 버튼도 이 한계를 우회하지 못합니다. 관측은 시각 순서대로 누적하여 미래 점을 미리 사용하지 않습니다.

2번은 같은 출발 시 카메라 관측에서 왼쪽 평지와 오른쪽 오르막 영역의 점을 각각 TLS 평면으로 추정한 뒤, 경사가 작은 쪽을 선택합니다. 추정에는 기본 경사 설정값이나 지면 높이 함수를 넣지 않습니다. 두 면이 모두 관측되지 않거나 평면 추정 조건을 만족하지 않으면 출발을 보류합니다. 선택 후 경로는 성공적으로 연결된다는 기존 가정을 유지합니다. 오른쪽 10도도 20도 한계 이내이지만, 이 예시의 경로 선호는 더 완만한 노면입니다.
