# 주행가능성 시나리오

[통합 HTML 열기](index.html)

하나의 HTML 안에서 위쪽의 시나리오 버튼을 선택합니다. 변경하면 출발점으로 돌아가고 점군, 경사 지도, 의미분할 지도와 경로를 다시 계산합니다. 센서 설치 설정은 유지합니다.

| 번호 | 기본 오르막 | 요철 생성 계수 | 나무와 돌 장애물 |
| --- | --- | --- | --- |
| 1 | 0도 | 0cm | 없음 |
| 2 | X 6m부터 10도 | 4cm | 없음 |
| 3 | 0도 | 4cm | 있음 |
| 4 | X 6m부터 10도 | 4cm | 있음 |

기본 오르막이 0도인 3번도 요철로 인한 국소 경사는 존재합니다. 요철 생성 계수는 실제 최대 고저차를 뜻하지 않습니다. 1번의 지형 높이는 모든 셀에서 0입니다. 1번과 2번에는 배경 나무도 표시하지 않습니다.

카메라 높이 29cm, 하향 4도와 라이다 높이 30cm, 하향 12도를 기본으로 사용합니다. OAK-D Lite 화각을 가정하며 셀별 경사는 관측한 점군에서 계산합니다. 의미분할은 가상 정답 라벨이며 경로는 전체 가상 환경을 아는 외부 계획기가 성공한다는 가정입니다. 실제 학습 모델이나 센서 및 로봇 성능 검증 결과는 아닙니다.

Three.js와 계산 워커가 내장된 독립 HTML입니다. `?scenario=1`부터 `?scenario=4`까지 링크로 바로 선택할 수 있습니다. 기존 before_obstacles.html과 with_obstacles.html은 이전 링크 호환을 위해 보관합니다.

수정 후 `python3 source/build.py`로 통합 HTML을 생성합니다.
