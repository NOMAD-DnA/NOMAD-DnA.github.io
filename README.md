## 회의 핑

같은 페이지를 연 뒤 오른쪽 아래 **핑 켜기** → 가리킬 곳을 클릭합니다. 상대는 모드를 켜지 않아도 볼 수 있습니다. 이름은 표시하지 않고 5초 뒤 사라집니다. **Esc**로 종료하면 원래 화면 조작으로 돌아갑니다.

- 지도·지원되는 3D 표면/점군: 좌표로 공유해 서로 다른 확대·시점에도 같은 지점을 표시합니다.
- 글·사진·영상·일반 화면: 해당 요소 안의 상대 위치를 공유하며 `화면 핑`으로 표시합니다. 영상 시간·시뮬레이션 재생은 동기화하지 않습니다.
- 같은 URL의 페이지끼리 공유합니다. 문서에 삽입된 뷰어도 지원합니다. 공유 상대가 없으면 `내 화면에만 표시`됩니다.
- HTTPS 또는 localhost에서 사용합니다. 공개 MQTT 중계(EMQX)에 연결하며 별도 계정은 필요하지 않습니다. 중계 접속이 막히면 공유되지 않으므로 연결 인원을 확인하세요. 접속을 끊은 동안의 핑은 저장·재전송하지 않습니다. 공개 회의용이며 비공개 정보는 표시하지 마세요.

새 HTML을 추가하면 `python3 scripts/add-meeting-ping.py`로 공통 기능을 붙입니다. 구현은 `assets/meeting-ping.js`, 좌표 어댑터는 각 뷰어에 있습니다. 전송은 클릭 좌표뿐이며 기록을 저장하지 않습니다.
